<h1 align="center" id="title">Educationist</h1>

Welcome to the GitHub repository of the app <strong>Educationist</strong>, an ad-free catalogue of Cambridge past papers for students and teachers.
Available for free on the <a href="https://play.google.com/store/apps/details?id=com.harisssahmad.educationist" target="_blank">Play Store</a>.<br/>

This repository serves as the <i>database</i> for the app. The `v2` folder holds the past papers used in the latest version, organised by board:

- `O-Level`
- `IGCSE`
- `AS-and-A-Level`
- `Pre-U`

Each board has a `subjects.json` index and one `<Subject>-<Code>.json` file per subject, listing every paper's title and download link.

Found a broken link or a missing paper? Please [open an issue](https://github.com/harisssahmad/educationist/issues).
